## 1. 路线总览（v3 重要修正）

**v2 的结论是「ArduSub + BlueROV2，别自研控制器」。金带来 FinsROV 之后，这个结论要修正——两条路不是一回事。**

```
FinsROV（学习主线）  →  读得懂、能复现、约 8000 元做出来
ArduSub（参照系）    →  工业标准，判断"我做得对不对、差距在哪"
```

| | **FinsROV** | **ArduSub + BlueROV2** |
|---|---|---|
| 性质 | 交大 FINS 实验室教学 / 科研平台 | 工业级开源飞控，事实标准 |
| 固件核心 | **约 150 KB**，读得完 | ardupilot 15k★，读不完 |
| 深度 | 10–20 m | 100 m+ |
| 文档 | **中文 + B 站视频教程** | 英文为主 |
| 采购 | **淘宝，全部可买** | 官方进口为主 |
| 成本 | **约 8000 元** | 整机两三万起 |
| 适合 | 搞懂原理、动手做出来、做研究 | 要可靠、下深水、上生产 |

**为什么改：** v2 把"做一个能用的 ROV"和"学懂 ROV 怎么工作"当成了同一件事。对金的目标（从零学会做），**看得完的东西才能学会**——FinsROV 那 150 KB 固件可以全读懂，ArduSub 只能读文档。等有了判断力，再翻 ArduSub 对照。

> ⚠️ 许可差异：FinsROV 是 **MIT**（宽松）；ArduSub 是 **GPL-3.0**（传染性）。

## 2. ★ 学习主线：FinsROV（已接入本地）

| 仓库 | ★ | 语言 | 更新 | 许可 |
|---|---|---|---|---|
| `FPJ-GAOGE/FinsROV-An-Underwater-Camera-Based-Multi-Robot-Platform` | **265** | C | 2026-09-10 | **MIT** |

上海交通大学 FINS 实验室开源的低成本水下机器人平台。配套论文 AUCAMP（水下多机器人低成本分布式定位，arXiv 2506.09876）。

**规格**：40×35×15 cm ｜ 4.85 kg ｜ 深度 10–20 m ｜ 约 2 h 续航 ｜ 8 推进器 + 4 舵机（双二自由度云台）+ 4 路 MS5837 水深计 ｜ 控制器是大疆 RM C 板（STM32F407IGHx）

**已克隆到** `./FinsROV/`（28 MB，稀疏检出，剔除了 220 MB 的 STM32 手册和重复 CAD）

**必读的三份文档**：

1. `Code/Lower_Level_Controller/README.md` —— 全仓库最有价值的一份，11.7 KB 双语讲完固件架构
2. `Making_Instructions/README.md` —— 接线指南，每个螺丝孔接什么
3. `Code/Joystick_Control/readme.md` —— 上位机环境与操作

**最值得学的三处设计**：

- **`Device` 抽象**（`Usermain.h`）—— `Init / Receive / Handle` 三接口 + 指针数组注册设备。加设备不改调度逻辑
- **水压差分做姿态外环**（`Propeller.cpp`）—— 4 路水压计的深度差解算倾斜角，不漂移但慢；内环用 IMU 陀螺仪补高频
- **三段式传感器流水线**（`Sensor.cpp`）—— 下发转换 / 读结果+下发下一个 / 算深度，把传感器等待时间藏起来

## 7. 建议动手顺序（v3 重排）

**阶段一 · 读懂 FinsROV 的固件**（零成本）
读 `Code/Lower_Level_Controller/README.md` → `Making_Instructions/README.md` → `Usermain.cpp` → `Propeller.cpp`。目标：**画出"传感器采样 → PID → 推进器"的完整数据流图**。

**阶段二 · 决定走哪条路**
- 想搞懂原理、预算八千、10–20 m 够用 → **FinsROV 路线**，照 BOM 采购 + B 站视频装配
- 要下深水、要可靠、预算充足 → **BlueROV2 路线**，买成品照 ArduSub 文档走
- 拿不准就先做阶段一，读完自然有判断

**阶段三 · 仿真验证（如果走 FinsROV 路线，这步要自己做）**
FinsROV 无官方仿真。可用 Gazebo + `bluerov2_gz` 之类搭个近似模型，把 PID 参数先调出来，减少下水次数。

**阶段四 · 硬件装配**
先做**密封**和**配平**——这两个决定下水成败，推进器是次要的。⚠️ 上电前必读 `FinsROV-项目解读.md` 第六节的三个已知坑。

**阶段五 · 下水**
从小水池开始。**先测密封，再通电动推进器**——顺序别反。

**阶段六 · 加自主**
SLAM / 目标跟踪等前面稳了再说。FinsROV 的定位能力本身就在相机多机定位方向，可以顺着 AUCAMP 论文往下走。

## 8. 两个针对哈尔滨的提醒

- **气候**：冬季长、结冰期长，户外水域大半时间不能用。实机测试往夏天集中，其余时间靠仿真和室内水池。
- **低温**：低温让锂电池容量显著下降、O 型圈密封件变硬失去弹性——水下机器人最怕这两点。备件按低温工况重算，别照搬常温参数。**FinsROV 用的是航模锂电池 + 氟胶 O 型圈，这两样都受低温影响，采购时留意。**
